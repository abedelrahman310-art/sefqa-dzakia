# قواعد المشروع — صفقات ذكية (Always On)

> ضع هذا الملف في `.agents/rules/safaqat-rules.md` وفعّله بنمط **Always On**.

## 1) السياق
منصة GovTech + LegalTech + AI لتسيير دورة حياة الصفقات العمومية في الجزائر.
ثلاثة أدوار: المتعامل الاقتصادي، المصلحة المتعاقدة، الإدارة المركزية.
النبرة رسمية وهادئة. ممنوع الأسلوب الترويجي المبالغ فيه، وممنوع طابع crypto/neon.

## 2) التقنيات (ثابتة، لا تُغيَّر)
- الواجهة: React 18 + TypeScript + Vite + wouter (الراوتر الحالي كما هو)
- التنسيق: Tailwind CSS (v3) + shadcn/ui
- الخادم الرسمي: Django 6 + Django REST Framework في `backend/`
- قاعدة البيانات: PostgreSQL 16 عبر Django ORM وترحيلات Django
- pnpm فقط للواجهة (ممنوع npm/yarn وممنوع إنشاء lock files أخرى)
- **ممنوع Next.js**، وممنوع اعتماد Drizzle أو MySQL أو Express في أي عمل جديد
- `server/` و`shared/` إرث Node مُجمَّد: لا تطوير فيهما دون قرار صريح
- ممنوع إضافة أي dependency دون ذكرها صراحة في الخطة وانتظار الموافقة

## 3) العربية و RTL
- العربية RTL هي اللغة الأساسية، والفرنسية LTR ثانوية.
- اللغة تُحفظ في `localStorage` بالمفتاح `lang`، والافتراضي `ar`.
- عند تغيير اللغة يُحدَّث `lang` و`dir` على عنصر `<html>`.
- **خصائص CSS المنطقية فقط**: `ms-*` `me-*` `ps-*` `pe-*` `start-*` `end-*` `text-start` `border-s`.
- ممنوع: `left/right` و`ml/mr/pl/pr` و`text-left/right` و`space-x-*` (استعمل `gap`).
- كل نص ظاهر للمستخدم يأتي من ملفات الترجمة، لا نصوص مكتوبة داخل المكونات.
- الأيقونات الاتجاهية (أسهم، chevrons) تُعكس في RTL.

## 4) التصميم
- الألوان عبر متغيرات CSS/Tailwind tokens فقط، ولا ألوان hex داخل المكونات:
  - Navy أساسي، Emerald ثانوي، Gold فاتح كلمسة
- خط Cairo للعربية.
- استعمل مكونات shadcn/ui قبل كتابة مكون جديد.
- المراجع (ixartz/SaaS‑Boilerplate وsamsyntx/nextjs‑saas‑landing‑page وshadcnstore/shadcn‑dashboard‑landing‑template) للإلهام فقط. **ممنوع نسخ الكود أو المحتوى**.

## 5) نزاهة المحتوى
- ممنوع اختلاق عملاء أو شعارات أو شهادات أو أرقام أو إحصائيات.
- إن لزم عنصر نائب فليكن واضحًا: `[نص تجريبي]`، ولا يظهر كحقيقة.
- لا بيانات صفقات حقيقية ولا بيانات شخصية في الكود أو الاختبارات أو الطلبات.

## 6) الأمان
- لا أسرار في المستودع. المفاتيح في `.env` فقط، و`.env` في `.gitignore`.
- **الدور والصلاحيات من الخادم فقط**: الخطاف `/api/auth/me/` مصدر الحقيقة، ولا يُستعمل
  أي دور محفوظ في `localStorage` أو أي قيمة يرسلها المتصفح لتقرير الصلاحية.
- ممنوع تنفيذ أوامر مدمِّرة (`rm -rf`، `git reset --hard`، `drop`) دون طلب موافقة صريحة.

## 7) انضباط العمل
1. ابدأ دائمًا بـ **Plan artifact** يتضمن: الملفات المتأثرة، الملفات الجديدة، الـ dependencies (إن وُجدت). انتظر موافقتي قبل التنفيذ.
2. نفّذ ما طُلب فقط. أي اقتراح إضافي يُدوَّن في نهاية التقرير ولا يُنفَّذ.
3. لا تعدّل ملفات خارج نطاق المهمة، ولا تعِد تنسيق ملفات لم تلمسها.
4. تعريف الإنجاز: `pnpm --filter client typecheck` و`pnpm --filter client lint`
   و`pnpm --filter client build` تنجح، و`python -m pytest -q` داخل `backend` بلا فشل.
5. في نهاية كل مهمة قدّم: قائمة الملفات المتغيرة، مخرجات الأوامر، وما لم يُنجَز أو تعذّر.
6. إن تعارضت افتراضات الطلب مع حالة المستودع، توقّف واعرض الفروقات ولا تخمّن.
